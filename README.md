# 날도와줘 · DailyHelpMe!!

맥 화면 구석에 사는 **데스크톱 펫 비서**입니다. 펫(기본: 봉고캣)과 대화하면 일정·할 일·루틴을 기억해 두었다가 알려주고, 일기도 함께 써요. ChatGPT 계정의 Codex로 답장하며, 데이터는 모두 내 맥에 저장됩니다.

- 현재 버전: **0.1.0-beta.1** (미공증 베타, Apple Silicon · macOS 26 이상)
- 문서: [설치 안내](docs/INSTALL.md) · [개인정보 안내](docs/PRIVACY.md) · [배포 절차](docs/RELEASING.md) · [변경 기록](CHANGELOG.md)
- 라이선스: [MIT](LICENSE) · [외부 구성 요소 고지](THIRD_PARTY_NOTICES.md)

## 빠른 시작

필요한 것: **Python 3.10+**, **Codex CLI**(ChatGPT 계정 로그인)

```bash
npm install -g @openai/codex   # Codex CLI가 없다면
codex login                    # ChatGPT 계정으로 로그인
bash scripts/run-python-pet.sh # 실행 (= npm run pet:start)
```

- 앱의 **설정 → ChatGPT 로그인**으로도 로그인할 수 있어요.
- Codex 실행 파일을 직접 지정하려면 `DOA_CODEX_BIN=/절대/경로/codex`
- `.env`, 별도 서버, API 키는 필요 없어요.

## 사용법

펫을 **클릭**하면 작은 서랍이 열리고, **드래그**로 옮기고, **우클릭**이나 메뉴 막대에서 숨기기·종료를 할 수 있어요. 서랍은 제목 부분을 끌어 옮기고, 하단 슬라이더로 투명도(최대 65%)를 조절합니다.

| 탭 | 할 수 있는 일 |
| --- | --- |
| **오늘** | 오늘 일정·마감·루틴을 타임라인으로. 지난 미완료 항목은 상단 *이전 미완료*에 표시 |
| **대화** | 펫과 채팅 (Return 전송, Shift+Return 줄바꿈). 말풍선 **더블클릭 = 확인 표시**, **우클릭 = 북마크** |
| **달력** | 월간 달력 / 주간 시간표. 날짜를 골라 그날 일정 확인, 바로 일기 열기 |
| **할 일** | 데드라인·버킷리스트·일정·루틴 전체 목록 (완료 항목 숨기기 가능) |
| **일기** | 일기 목록과 **태그별 보기**, ＋로 새 일기 쓰기. 날씨·기분·태그 달기, **북마크한 말풍선 모아 보기** |

### 일정과 할 일

- 대화로 말하면 AI가 일정·데드라인·루틴·버킷리스트를 추가·수정·완료·삭제해요. 직접 `＋`로 추가해도 됩니다.
- AI가 일정을 만들면 답장 아래에 **상세 보기 카드**가 붙어요.
- 항목을 누르면 상세 화면에서 **2차 일정**(작은 단계)을 추가·체크·정렬할 수 있어요. 목록에 `작업 (3/6)`처럼 진행도가 보입니다.
  - 2차 일정을 모두 끝내도 1차 일정은 **직접** 완료해야 해요.
- 루틴 완료 체크는 매일 **새벽 5시(한국 시간)** 에 초기화됩니다.

### 알림 (선톡)

일정 시각, 루틴 시각, 마감 전날 정오, 24시간 대화가 없을 때 펫이 먼저 말을 걸어요. 구독 사용량을 쓰지 않는 로컬 문구이고, 앱이 켜져 있고 맥이 깨어 있을 때만 동작합니다.

### 일기

- 일기 탭을 열면 **목록**이 먼저 보여요. 위쪽 **태그 선택**으로 원하는 태그의 일기만 골라 볼 수 있어요.
- **＋**를 누르면 날짜를 골라 새 일기를 쓰고, 목록에서 일기를 누르면 그날 일기를 열어요. **‹ 목록**으로 돌아갑니다.
- 입력하면 약 0.7초 뒤 **자동 저장**돼요. (제목 200자, 본문 30,000자)
- **날씨·기분**을 고르고, **태그**를 쉼표로 구분해 달 수 있어요. (예: `산책, 카페` — 최대 20개)
- **대화로 AI 초안 쓰기**: 그날 대화를 바탕으로 1인칭 일기 초안을 만들어요. 미리보기를 확인한 뒤 *이 초안 적용*을 눌러야 저장됩니다.
- **북마크**: 대화에서 남기고 싶은 말풍선(내 것/AI 것 모두)을 북마크하면 일기 탭 맨 위 **★ 북마크** 버튼에서 모아 읽을 수 있어요.
  - 맥: 말풍선 **우클릭 → 북마크하기** · 모바일: 말풍선 시각 옆 **☆** 누르기
- **설정 → 일기 내보내기**로 JSON / Markdown 파일로 저장할 수 있어요.

### 이모지 · 스티커

대화 입력창 옆 **☺**에서 이미지(PNG·JPG·WebP, 4MB 이하)를 이름과 함께 등록해 쓸 수 있어요.

- **이모지**: 글 사이에 넣어 함께 전송 (AI에는 이름만 전달)
- **스티커**: 단독 메시지로 전송, **AI를 호출하지 않음**

### 웹 검색

날씨·뉴스처럼 최신 정보가 필요한 질문에는 웹 검색을 하고 답변에 **출처 링크**를 붙여요. **설정 → 웹 검색 사용**에서 끌 수 있습니다.

### 꾸미기

**설정 → 이름 · 테마 · 이미지**에서 펫 이름(30자), 테마색, 펫 이미지(PNG·JPG·WEBP)를 바꿀 수 있어요. *꾸미기 전체 기본값*으로 봉고캣으로 돌아갑니다.

봉고캣은 키보드를 칠 때 같이 타이핑해요. 키 **횟수 변화만** 확인하며 어떤 키를 눌렀는지는 읽지 않아요. **설정 → 키보드 입력에 봉고캣 반응**에서 끌 수 있습니다.

## 아이폰 · 아이패드에서 쓰기 (Tailscale)

맥 앱과 **같은 데이터**(대화·일정·일기·북마크)를 모바일 브라우저에서 쓸 수 있어요. 답장은 맥의 Codex가 만듭니다.

1. 맥 앱 **설정 → 모바일 접속 허용**을 켜요. (연결 코드가 표시됨)
2. 맥 터미널에서:
   ```bash
   tailscale serve --bg --https=8765 http://127.0.0.1:8765
   ```
3. 아이폰도 같은 Tailscale에 연결하고, Safari로 `https://맥이름.테일넷이름.ts.net:8765`에 접속해 연결 코드를 입력해요.
4. **공유 → 홈 화면에 추가** → 홈 화면 앱에서 **설정 → 알림 켜기** (iOS 16.4 이상)
5. **테스트 알림 보내기**로 확인!

- 로그인은 30일 유지. 맥 앱의 **연결 초기화**로 모든 기기를 해제할 수 있어요.
- 맥이 꺼져 있거나 잠자기 상태면 답장·알림이 오지 않아요.
- 연결 끄기: `tailscale serve --https=8765 off`

## 데이터와 개인정보

- 저장 위치: `~/Library/Application Support/DOA Pet/doa.sqlite3` (`DOA_DATA_DIR`로 변경 가능)
- 로컬 SQLite에 **암호화 없이** 저장하며, 파일 권한은 사용자 전용이에요.
- AI 답장 시 OpenAI로 전달되는 것: 최근 대화 50개, 프로필, 일정, 최근 일기 14개(날씨·기분·태그 포함). 2차 일정과 스티커는 전달하지 않아요.
- ChatGPT 구독의 Codex 사용량 한도가 적용되며, 별도 API 결제로 넘어가지 않아요.
- 인증 토큰은 Codex가 관리하고 앱은 읽지 않습니다.

자세한 내용은 [개인정보 안내](docs/PRIVACY.md)를 참고하세요.

## 개발

```bash
npm run pet:start    # 실행
npm run pet:test     # 테스트
npm run pet:build    # build/날도와줘.app 생성 (Finder에서 .app 실행)
npm run pet:release  # dist/에 DMG·ZIP·SHA256 생성 (업로드는 하지 않음)
```

- 코드: `desktop/python/` (앱 + 모바일 서버 `mobile/`), 빌드 도구: `scripts/`
- 앱 번들에 Python·Qt는 포함되지만 **Codex CLI는 따로 설치**되어 있어야 해요.
- 아이콘은 `dailyhelpme_logo.png`에서 빌드 시 자동 생성 (`.venv-pet/bin/python scripts/generate-brand-icons.py`)
- 예전 Next.js 버전의 코드·DB 백업은 Git에서 제외된 `.local-backups/`에만 있어요. 개인 정보가 있을 수 있으니 공개 저장소나 배포 파일에 넣지 마세요.
- 기존 사용자 데이터를 위해 내부 경로(`DOA Pet`), 환경변수, 번들 식별자는 예전 이름을 유지해요.
