# 날도와줘 · DailyHelpMe!!

현재 실행 대상은 **날도와줘(DailyHelpMe!!) — Python/PySide6 기반 데스크톱 펫 앱**입니다. `desktop/python/`에 앱과 모바일 접속 서버, `scripts/`에 실행·빌드 도구가 있습니다. 루트의 `package.json`은 `npm run pet:start`, `pet:build`, `pet:test` 실행 별칭만 제공합니다. Python 앱 실행에 Node 웹앱 의존성 설치는 필요하지 않습니다.

이전 Next.js·Prisma·Node 스케줄러·Docker 구성은 현재 앱에서 사용하지 않아 제거했습니다. 이전 코드·DB·환경설정은 Git에서 제외되는 `.local-backups/`의 검증된 압축 파일에 로컬로 보관했습니다. 이 백업은 개인 정보를 포함할 수 있으므로 공개 저장소나 배포 파일에 넣지 마세요. 현재 Python 앱의 데이터 저장 공간과는 별개입니다.

## 설치 파일 배포 준비

현재 버전은 **0.1.0-beta.1**이며 공개 릴리스 준비 중입니다. 로컬 준비 파일을 공개 배포 완료로 표시하지 않습니다. 현재 개발 맥에서 만든 바이너리는 **Apple Silicon / macOS 26 이상**입니다. 실제 번들의 CPU·OS 요구 사항을 검사해 기록하며, Intel·구형 macOS용 검증 빌드는 아직 없습니다. 첫 배포는 **미공증 베타**로 준비하며 macOS에서 첫 실행 안내가 나올 수 있습니다. 다른 맥의 새 설치 검증과 소스 커밋·태그 확정이 남아 있습니다. ## macOS 독립형 데스크톱 펫 (Python)

웹 서버 없이 실행하는 Python/PySide6 앱입니다. 투명한 펫을 클릭하면 서랍을 열고, 드래그로 위치를 옮기고, 우클릭이나 메뉴 막대에서 숨기거나 종료할 수 있어요. 기존 DOA의 말투와 기억·일정 기능을 로컬 SQLite로 옮겼습니다. 웹 프로젝트와는 별도의 저장 공간을 사용하며 기존 DB를 자동으로 가져오지는 않습니다.

### 처음 실행

Python 3.10 이상과 ChatGPT 계정으로 로그인할 수 있는 Codex CLI가 필요합니다. Homebrew Python 또는 python.org의 Python을 사용할 수 있습니다. 프로젝트의 Node 의존성 설치나 `.env`, Next.js, Prisma, 별도 서버는 필요하지 않습니다.

```bash
# Codex CLI가 없다면 설치 (Node.js/npm 필요)
npm install -g @openai/codex

# 기존 ChatGPT 계정으로 로그인. 브라우저의 로그인 세션만으로는 CLI 로그인이 되지 않아요.
codex login

# Python 가상환경과 필요한 패키지를 준비한 뒤 펫 실행
bash scripts/run-python-pet.sh
# npm이 설치되어 있다면 같은 실행 명령:
npm run pet:start
```

앱의 ‘연결 → ChatGPT 로그인’에서도 로그인할 수 있습니다. CLI가 PATH에 없으면 설치된 VS Code/Cursor 확장에 포함된 실행 파일도 찾아봅니다. `DOA_CODEX_BIN=/절대/경로/codex`로 직접 지정할 수도 있습니다.

개인용 로컬 앱에서 공식 Codex CLI의 저장된 ChatGPT 인증을 사용합니다. API 키를 입력하거나 브라우저 쿠키를 복사하지 않습니다. 앱은 API 키 환경변수를 전달하지 않고 ChatGPT 로그인 방식을 요구합니다. Codex의 `--ignore-user-config`, `--ephemeral`, `--output-schema` 옵션을 지원하는 최신 버전이 필요합니다.

이것은 **ChatGPT 구독으로 사용하는 Codex 기반 대화**입니다. ChatGPT 웹의 특정 모델·기존 대화·메모리가 그대로 이어지는 것은 아닙니다. 사용 가능한 구독과 사용량 한도가 적용되며, 한도를 넘으면 답장 오류를 표시합니다. 로컬 앱이어도 AI 답장에는 인터넷이 필요합니다. 최근 대화 50개와 저장된 프로필·일정이 답장 생성 시 OpenAI로 전달됩니다. 별도 API 결제로 자동 전환하지 않습니다.

참고: [Codex 로컬 앱 인증](https://learn.chatgpt.com/docs/app-server), [저장된 인증과 구조화 응답](https://learn.chatgpt.com/docs/non-interactive-mode). 상용·호스팅 서비스로 배포하려면 별도 인증·등록 조건을 검토해야 합니다.

### 기능

- 투명한 펫 창, 둥실거리는 모션, 드래그 위치 저장, 말풍선, 메뉴 막대 제어
- macOS에서 펫을 일반 창보다 높은 레벨에 표시하고 모든 데스크톱·전체 화면 공간에 참여하도록 설정
- 동글동글한 ‘작은 서랍’: 오늘 일정·지난 대화·달력·전체 실행목록을 작은 패널에서 확인
- 작은 서랍의 투명도(0~65%)·위치·선택 탭·켜짐 상태 저장; 펫 클릭이나 메뉴 막대에서 켜고 끄기
- 독립 대화창과 ChatGPT 계정의 Codex를 통한 답장; 실패 시 마지막 메시지 재시도
- 대화 중 프로필 메모, 데드라인·버킷리스트·루틴·일정의 추가·수정·완료·삭제
- 기억 목록, 직접 추가·완료·삭제, 날짜별 달력, 프로필 직접 편집
- 대화의 AI 메시지를 더블클릭해 로컬 확인 표시
- 일정 시각, 루틴, 마감 전날 정오, 24시간 무대화 안부 알림; 재시작 시 중복 방지
- 루틴 완료 체크는 한국 시간 새벽 5시 기준으로 초기화

선톡은 구독 사용량을 쓰지 않는 로컬 문구입니다. 앱이 켜져 있고 맥이 깨어 있어야 표시합니다. 잠자기 후에는 지난 일정과 오늘 놓친 루틴을 확인합니다. 맥 앱 자체는 기존 웹앱의 로그인·서버 스케줄러를 사용하지 않습니다. 선택적으로 모바일 접속과 Web Push를 켤 수 있습니다. 대화창을 닫아도 메뉴 막대와 펫은 계속 실행됩니다. 서랍 대화는 최근 50개부터 표시하며 이전 대화를 계속 불러올 수 있습니다. 전체 내역은 DB에 남습니다.

데이터는 `~/Library/Application Support/DOA Pet/doa.sqlite3`에 저장합니다. `DOA_DATA_DIR`로 다른 위치를 지정할 수 있습니다. 대화·기억은 암호화하지 않은 로컬 SQLite 파일에 저장하며 폴더 접근 권한을 사용자 전용으로 설정합니다. 인증 토큰은 앱이 읽거나 복사하지 않고 Codex가 관리합니다.

기본 캐릭터는 키보드에 반응하는 투명 봉고캣입니다. 설정에서 이미지를 바꾸거나 `DOA_PET_IMAGE=/절대/경로/character.png npm run pet:start`로 정지 이미지를 지정할 수 있습니다.

펫은 다른 앱을 사용할 때도 맨 앞에 남도록 macOS 창 정책을 적용합니다. macOS의 잠금 화면이나 시스템 보안 화면 위까지 표시하는 기능은 아닙니다. 화면 고정 문구에는 하트를 사용하지 않고, 새 AI 답장도 담백한 존댓말을 사용하도록 지시합니다. 이미 저장된 대화는 그대로 남습니다.

### 작은 서랍 사용법

실행하면 펫과 함께 작은 패널이 열립니다. 펫을 클릭하면 패널을 켜거나 끌 수 있고, 패널의 `×` 또는 Escape로 숨길 수 있어요. 메뉴 막대·펫 우클릭의 ‘작은 서랍 보이기’에서도 다시 열 수 있습니다. 제목 부분을 드래그해서 옮기고 하단 슬라이더로 패널 전체의 투명도를 조절합니다. 완전히 투명해져서 조작하지 못하는 일이 없도록 최대 65%까지 지원합니다.

- **오늘**: 한국 시간 기준 오늘의 일정·마감·해당 요일 루틴을 타임라인으로 표시합니다. 어제 이전의 미완료 일정·데드라인은 상단 **이전 미완료**에 계속 표시합니다. 원래 날짜·마감 시각은 유지하며, 완료하면 이 목록에서 사라집니다. 반복 루틴은 오늘 요일의 항목만 표시합니다. 오늘의 시간 미지정 항목은 그 아래에 모으고, 시간이 있는 항목은 시간순으로 표시합니다.
- **대화**: 최근 50개부터 표시하고 ‘이전 대화 더 보기’로 더 오래된 로컬 대화를 불러옵니다. 읽는 중에는 자동 갱신으로 스크롤을 맨 아래로 옮기지 않습니다.
- **달력**: 기본 화면은 **월간 달력**입니다. 월간 달력과 그날 일정 목록은 하나의 긴 스크롤로 이어지며, 일정 목록은 항목 수만큼 늘어납니다. 필요하면 **주간 시간표**로 전환합니다. 날짜를 고른 뒤 **일기 쓰기/보기**로 해당 날짜의 일기를 바로 열 수 있습니다. 원본 웹처럼 일요일부터 시작하고 반복 루틴을 해당 요일에 표시합니다. 시간 미지정 일정은 상단에 모으고, 날짜를 누르면 아래 목록에서 전체 제목·완료 여부를 확인할 수 있습니다.
- **할 일**: 데드라인·버킷리스트·일정·루틴을 모아 보여줍니다. 완료 항목은 기본으로 숨기며 체크해서 함께 볼 수 있습니다.
- **일기**: 날짜별 제목·본문을 작성합니다. 입력 후 약 0.7초에 자동 저장하고, 날짜 이동·서랍 숨기기·앱 종료 전에도 저장합니다. 날짜를 누르면 달력으로 다른 날을 선택합니다. 삭제는 두 번 눌러 확인하며, 제목 200자·본문 30,000자까지 지원합니다.

**설정 → 일기 내보내기**에서 전체 일기를 **JSON** 또는 **Markdown(.md)** 파일로 저장합니다. JSON에는 날짜·제목·본문·생성 및 수정 시각이 들어가며, Markdown은 날짜순으로 묶습니다. 일기는 같은 맥의 SQLite DB에 저장하며 AI가 대화에 참고합니다. 일반 대화에는 최근 14개 이내의 일기(본문 각 4,000자, 합계 24,000자 이내)를 전달합니다. **일기 → 대화로 AI 초안 쓰기**는 선택한 날짜의 대화와 기존 일기를 바탕으로 1인칭 일기 본문을 만듭니다. 초안은 미리보기에서 확인한 뒤 **이 초안 적용**을 눌러 저장하며, 생성 중 일기가 변경됐다면 덮어쓰지 않습니다. 이 기능도 ChatGPT 구독 사용량을 사용합니다. 모바일에서도 같은 일기를 작성하고 설정에서 파일을 내려받을 수 있습니다. 저장 상태가 ‘맥에 저장했어요’로 바뀐 뒤 브라우저를 닫아주세요.

별도의 큰 창 없이 서랍 안에서 모든 기능을 사용합니다. **대화**에서 바로 입력·전송하고, Return은 전송, Shift+Return은 줄바꿈입니다. 내 메시지는 오른쪽, AI 답장은 왼쪽 말풍선으로 표시하고 날짜 구분선·시각·연속 답장 묶음을 보여줍니다. AI 답장을 더블클릭하면 로컬 확인 표시를 바꿉니다.

기존 일정·데드라인·버킷리스트·루틴은 **1차 일정**입니다. 오늘·할 일·달력 목록에서 제목이나 카드를 한 번 누르면 상세 화면이 열리고, **2차 일정**에서 ‘컴퓨터 켜기’, ‘작업 파일 열기’처럼 작은 단계를 직접 추가할 수 있습니다. 단계 제목을 고치거나 체크·삭제하고 `↑`·`↓`로 순서를 바꿀 수 있으며 변경은 바로 저장합니다. 새 1차 일정은 먼저 저장한 뒤 다시 열어 단계를 추가합니다. **2차 일정을 모두 완료해도 1차 일정은 자동 완료되지 않습니다.** 상세 화면의 **1차 일정 완료** 또는 목록의 완료 원을 직접 눌러야 합니다. 반대로 1차 완료도 2차 체크를 바꾸지 않습니다. 루틴의 단계 목록은 유지하고 완료 체크만 매일 한국 시간 새벽 5시에 초기화합니다. 1차 일정을 삭제하면 소속 2차 일정도 삭제합니다. 2차 일정은 AI를 호출하지 않고 직접 편집하며 AI 대화 문맥에 포함하지 않습니다. 모바일에서도 같은 목록을 편집할 수 있습니다.

**오늘·달력·할 일**의 `＋`로 항목을 추가하고, 항목의 원을 눌러 완료·취소하고, 제목이나 카드를 한 번 눌러 상세·수정·2차 일정 화면을 엽니다. AI가 답장 중이어도 기존 일정 상세는 열 수 있으며 1차 일정 저장·완료는 답장 후 사용할 수 있습니다. 제목·날짜·시각·반복 요일은 서랍 안 편집 화면에서 변경할 수 있습니다. **설정**은 서랍 오른쪽 위에서 열고 프로필 편집·ChatGPT 로그인·애니메이션 설정을 사용합니다. 달력은 월 이동·오늘로 이동·날짜 선택·종류별 색 점을 지원하고 날짜 아래에 그날의 목록을 보여줍니다. 서랍을 열거나 달력·목록을 보는 동작은 AI 사용량을 쓰지 않습니다. 대화 메시지를 전송할 때 AI 답장을 요청합니다. 기존 앱이 실행 중이면 종료한 뒤 새 버전을 실행해주세요.

서랍·대화 말풍선·달력·펫 말풍선은 **ThinMulmaru(얇은물마루)** 폰트를 사용합니다. 폰트와 OFL 라이선스를 앱에 포함하므로 별도 폰트 설치나 실행 중 다운로드가 필요하지 않습니다. [폰트 출처](https://github.com/BinRecycle/ThinMulmaru).

펫 말풍선은 메시지 길이에 맞춰 작아지고 최대 300×94 크기까지만 커집니다. 긴 답장은 생략하지 않고 말풍선 안에서 스크롤해 읽을 수 있습니다. 말풍선에 마우스를 올려 읽는 동안에는 자동으로 숨기지 않습니다.

기본 챗봇 이름은 **봉고캣**이고, 투명 배경의 고양이가 작은 컴퓨터 키보드 앞에 앉아 있습니다. 입력하면 왼발·오른발 타이핑 자세로 바뀌고 약 0.18초 동안 입력이 없으면 대기 자세로 돌아갑니다. macOS에서는 다른 앱에서 타이핑할 때도 키 입력 횟수 변화에 반응합니다. Apple의 `CGEventSourceCounterForEventType`로 합계 변화만 확인하며 글자·키 종류·입력 내용은 읽거나 저장·전송하지 않습니다. 앱 밖의 키 이벤트를 가로채는 입력 감시 훅이나 별도 라이브러리는 사용하지 않습니다. 보조 키 단독 입력과 키를 길게 누를 때의 자동 반복은 시스템 집계에 포함되지 않을 수 있습니다. **설정 → 키보드 입력에 봉고캣 반응**으로 끌 수 있고, **펫 애니메이션 줄이기**를 켜도 멈춥니다. 직접 고른 이미지는 정지 이미지로 표시합니다. 모바일에는 대기 이미지가 보이며 전역 키보드 반응은 맥에서 동작합니다.

봉고캣 투명 프레임은 [QueenDekim/bongocat](https://github.com/QueenDekim/bongocat/tree/master/images/kb-mouse)의 MIT 공개 이미지이며, 소형 컴퓨터 키보드는 앱에서 그립니다. 원본 그림 출처와 라이선스를 `desktop/python/assets/bongocat/`에 함께 포함합니다. 기존에 바꾼 이름과 이미지는 유지하며 **꾸미기 전체 기본값**을 누르면 봉고캣 기본값으로 돌아옵니다.

**설정 → 이름 · 테마 · 이미지**에서 챗봇 이름(최대 30자), 테마색, 펫 이미지를 바꿀 수 있습니다. 이름은 대화 작성자·우클릭 메뉴·알림·AI의 이름에 반영하고 테마는 서랍·말풍선·달력·메뉴에 적용합니다. 이미지는 PNG·JPG·WEBP를 지원하고 앱 데이터에 복사하므로 원본 파일을 옮겨도 유지됩니다. 투명 PNG도 사용할 수 있습니다. **기본 이미지** 또는 **꾸미기 전체 기본값**으로 되돌릴 수 있고, 설정은 다음 실행에도 유지됩니다. 모바일에도 이름·테마·이미지가 반영되며 모바일 설정에서는 이름·색상을 직접 변경할 수 있습니다. 앱 파일 이름은 날도와줘이며 영문 이름은 DailyHelpMe!!입니다. 앱 아이콘·PWA 홈 화면 아이콘은 루트의 `dailyhelpme_logo.png`를 사용합니다.

### 아이폰·아이패드에서 같은 날도와줘 사용하기 (Tailscale)

Python 앱 안에 모바일 브라우저용 화면을 포함합니다. 별도 Next.js 서버를 띄우지 않고, 맥 서랍과 **같은 SQLite 대화·기억·일정**을 읽고 수정합니다. 모바일 대화도 맥에서 로그인한 Codex로 답장합니다. 기존 웹앱의 DB와는 합쳐지지 않습니다.

1. 새 맥 앱을 실행하고 **설정 → 모바일 접속 허용**을 켭니다. 서버는 `127.0.0.1:8765`에만 바인딩합니다. 설정 화면에 연결 코드가 표시됩니다.
2. 맥 터미널에서 아래 명령으로 Tailscale 전용 HTTPS 연결을 설정합니다. 기존 기본 HTTPS 서비스와 겹치지 않도록 별도 포트 `8765`를 사용합니다.

   ```bash
   tailscale serve --bg --https=8765 http://127.0.0.1:8765
   ```

3. 아이폰·아이패드에서도 같은 Tailscale 네트워크에 연결한 뒤, 위 명령에 표시된 `https://맥이름.테일넷이름.ts.net:8765` 주소를 Safari로 엽니다. 맥 설정 화면의 연결 코드를 입력합니다.
4. Safari **공유 → 홈 화면에 추가**를 누릅니다. 홈 화면에서 날도와줘를 다시 열고 **설정 → 알림 켜기**를 눌러 허용합니다. 필요하면 연결 코드를 다시 입력합니다.
5. **테스트 알림 보내기**로 수신을 확인합니다. 이후 AI 답장과 일정·루틴·마감·24시간 안부 알림을 이 기기로 보냅니다.

아이폰·아이패드 Web Push는 iOS/iPadOS 16.4 이상의 **홈 화면 웹 앱**에서 지원됩니다. Tailscale IP의 일반 HTTP 주소로만 접속하면 푸시를 사용할 수 없으므로 HTTPS 주소를 사용해주세요. [WebKit 안내](https://webkit.org/blog/13878/), [Tailscale Serve 문서](https://tailscale.com/docs/reference/tailscale-cli/serve).

모바일에서도 오늘 타임라인·대화·월간 달력·주간 시간표·실행목록·일기·프로필 편집을 사용할 수 있습니다. 모바일 시간표는 좌우·위아래로 스크롤합니다. 연결 코드는 앱 설정에서 복사할 수 있고, **연결 초기화**를 누르면 기존 모바일 로그인과 알림 구독을 모두 해제합니다. 이 기기만 해제하려면 모바일 설정의 **이 기기 연결 해제**를 사용합니다. 로그인은 30일간 유지됩니다. 모바일 대화 화면은 최대 최근 1,000개를 불러오며 전체 기록은 맥 DB에 보존됩니다.

Tailscale Serve는 해당 tailnet에 접속한 기기에서만 접근하는 연결입니다. 연결 코드 인증을 추가로 요구하며 공개 인터넷용 Funnel은 사용하지 않습니다. 푸시 발송에는 맥의 인터넷 연결이 필요하고, 맥에서 날도와줘가 종료되거나 잠자기 상태이면 새 답장·알림을 만들 수 없습니다. 브라우저 창을 닫아도 홈 화면 알림은 받을 수 있습니다. 앱 설정에서 모바일 접속을 끄면 로컬 모바일 서버를 닫습니다. Tailscale 연결 자체도 해제하려면 아래 명령을 실행합니다.

```bash
tailscale serve --https=8765 off
```

푸시 구독·VAPID 키·모바일 로그인은 같은 로컬 DB에 보관하며 앱이 최초 사용 시 생성합니다. 별도 VAPID 환경변수나 유료 API 키는 필요하지 않습니다. 실제 아이폰 알림 권한·수신은 기기에서 확인해야 합니다.

### 앱으로 묶기

```bash
npm run pet:build
open "build/날도와줘.app"
```

Finder에서는 `build/날도와줘.app`를 실행해주세요. 앱 내부의 `Contents/MacOS/DailyHelpMe` 실행 파일은 일반 앱 아이콘으로 보이지 않을 수 있습니다.

Python과 Qt는 앱 안에 묶지만 Codex CLI는 별도로 설치되어 있어야 합니다. 배포용 개발자 서명·공증은 포함하지 않습니다. 이전 Swift 래퍼 대신 Python으로 실행하므로 Swift SDK는 필요하지 않습니다.

```bash
npm run pet:test
```

날씨·뉴스처럼 최신 정보가 필요한 질문은 Codex의 [실시간 웹 검색](https://learn.chatgpt.com/docs/web-search)을 사용하고 답변에 출처 링크를 표시합니다. 예: “대전지역 오늘 날씨 어때?” 대화 내역의 출처를 누르면 브라우저에서 열립니다. 데스크톱·모바일 **설정 → 최신 정보가 필요하면 웹 검색 사용**에서 끌 수 있습니다. 검색할 때는 필요한 지역·날짜·주제만 질의하도록 지시하며, 확인하지 못한 최신 정보는 추측하지 않도록 합니다. 일기 초안 생성에는 웹 검색을 사용하지 않습니다. 검색 역시 ChatGPT 계정의 Codex 사용 가능 범위와 사용량 한도를 따릅니다.

2차 일정이 있는 항목은 오늘·달력의 그날 일정·할 일 목록에 `작업 이름 (3/6)`처럼 완료 수/전체 수를 표시합니다. 모두 체크해도 1차 일정은 직접 완료해야 합니다. AI가 새 일정을 등록한 답장 아래에는 생성된 일정별 상세 보기 카드가 붙으며, 눌러 상세·2차 일정 편집 화면을 엽니다. 카드는 저장되어 재실행 후에도 남고, 삭제한 일정은 삭제 상태로 표시합니다. 이 기능을 적용한 뒤 새로 생성한 AI 일정부터 카드가 연결됩니다. 데스크톱과 모바일에서 함께 사용할 수 있습니다.

대화 입력창 옆 **☺ → 이모지 / 스티커**에서 이름과 이미지를 등록하고 눌러 사용할 수 있습니다. PNG·JPG·WebP(4MB, 1,600만 화소 이하)를 지원하며, 앱 안에 최대 512px PNG로 복사해서 원본 파일 없이도 유지합니다. 커스텀 이모지는 입력 커서 위치에 이미지로 삽입되어 텍스트와 함께 전송되고, 스티커는 독립 메시지로 즉시 전송합니다. **스티커 전송은 AI를 호출하지 않으며**, 이후 AI 대화와 일기 초안용 기록에서도 제외됩니다. 텍스트 이모지는 이미지 자체 대신 등록한 이름만 AI에 전달합니다.

대화 속 이모지·스티커와 선택창의 이미지는 마우스를 올리면 약 8% 커졌다가 탄성 있게 돌아옵니다. 크기 효과는 주변 글과 말풍선 배치를 밀지 않습니다. 모바일에서도 같은 등록 목록과 대화 이미지를 사용하며, 터치 기기에서는 이미지를 눌러 선택합니다. 선택 목록의 ‘삭제’는 해당 이미지를 목록에서 숨기며, 이전 대화의 이미지는 보존합니다. 이미지는 로컬 SQLite DB에 저장되고, 연결 인증을 마친 모바일 기기에서만 앱 서버를 통해 읽을 수 있습니다.

앱의 한국어 이름은 **날도와줘**, 영어 이름은 **DailyHelpMe!!**입니다. 소스 저장소는 [jyhyun1008/dailyHelpMe](https://github.com/jyhyun1008/dailyHelpMe)입니다. 기존 사용자의 대화·설정·연결을 유지하기 위해 내부 데이터 경로(`DOA Pet/doa.sqlite3`), 환경변수와 macOS 번들 식별자는 유지합니다. 캐릭터 이름은 앱 이름과 별개로 계속 설정에서 바꿀 수 있습니다.

아이콘은 `dailyhelpme_logo.png`에서 생성합니다. `npm run pet:build`가 macOS `.icns`, PWA 192/512px, maskable 512px, Apple 터치 180px 아이콘을 함께 갱신합니다. 아이콘만 갱신하려면 `.venv-pet/bin/python scripts/generate-brand-icons.py`를 실행하세요.
