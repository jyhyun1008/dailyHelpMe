# 날도와줘 · DailyHelpMe!! 설치

첫 배포는 `0.1.0-beta.1`입니다. 배포 파일 이름의 CPU(arm64 또는 x86_64)와 함께 제공되는 `release.json`의 `minimum_macos`를 확인하세요. 현재 개발 맥에서 만든 파일은 Apple Silicon 전용이며 macOS 26 이상이 필요합니다. Intel·구형 macOS에서 확인한 빌드는 아직 없습니다.

## 설치와 첫 실행

1. 공식 저장소 https://github.com/jyhyun1008/dailyHelpMe 의 Releases에서 배포 파일을 받습니다. 아직 공개 릴리스가 없다면 소스 README의 실행 방법을 사용하세요.
2. ZIP을 풀거나 DMG를 열고 `날도와줘.app`을 응용 프로그램 폴더로 옮깁니다. 앱 번들 내부 실행 파일을 직접 꺼내지 마세요.
3. 앱을 실행합니다. 펫을 클릭하면 서랍을 열고, 우클릭 메뉴에서 설정·종료를 사용할 수 있습니다.
4. AI 대화를 사용하려면 별도로 설치한 Codex CLI와 본인의 ChatGPT 계정 로그인이 필요합니다. 앱에는 Codex나 로그인 정보가 포함되지 않습니다. GUI 실행에는 Python·Node.js 설치가 필요하지 않습니다. Codex 설치 방법에 따라 Node.js가 별도로 필요할 수 있습니다.
5. 설정의 `ChatGPT 로그인`을 누릅니다. CLI 설치 안내는 [공식 Codex 문서](https://developers.openai.com/codex/cli/)와 저장소 README를 확인하세요. AI 연결 전에도 일정·일기·스티커는 직접 사용할 수 있습니다.

## macOS 실행 확인

공증되지 않은 베타는 macOS에서 개발자를 확인하지 못했다는 안내가 나올 수 있습니다. 배포 파일의 출처와 SHA256을 확인하고 [Apple 공식 실행 안내](https://support.apple.com/102445)를 참고하세요. 보안 기능을 전체 해제하거나 격리 속성을 삭제하도록 안내하지 않습니다. 앱이 손상됐다는 메시지가 나오면 다시 내려받아 확인하고 이슈로 제보해주세요.

## 업데이트와 데이터

기존 앱의 메뉴에서 종료한 뒤 새 앱으로 교체합니다. 자동 업데이트는 아직 없습니다. 데이터는 기존 호환 경로인 `~/Library/Application Support/DOA Pet/`에 남습니다. 백업하려면 앱을 종료한 상태에서 이 폴더 전체를 복사하세요. 앱 파일을 지워도 이 데이터 폴더는 자동 삭제하지 않습니다. 일기는 설정에서 JSON·Markdown으로 따로 내보낼 수 있습니다.

아이폰·아이패드는 맥 앱의 모바일 접속을 켜고 본인의 Tailscale HTTPS 주소에 접속합니다. 공개 웹 서버가 제공되는 서비스는 아닙니다. 홈 화면에 추가해 사용하며, 새 아이콘이 표시되지 않으면 다시 추가해주세요.
