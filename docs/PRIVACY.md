# 날도와줘 개인정보 안내

날도와줘는 사용자의 맥에서 실행되는 앱입니다. 제작자가 운영하는 계정·대화 수집 서버나 사용량 분석 기능을 포함하지 않습니다.

## 맥에 저장하는 데이터

대화, 프로필, 일정, 2차 일정, 일기, 등록한 이모지·스티커·펫 이미지와 앱 설정을 로컬 SQLite 파일에 저장합니다. 대화 DB는 암호화하지 않으며 사용자 전용 폴더 권한을 적용합니다. 저장 경로는 `~/Library/Application Support/DOA Pet/`입니다. 앱 삭제만으로 기록을 자동 삭제하지 않습니다. 완전히 지우려면 앱을 종료하고 해당 폴더를 삭제합니다. 이 작업은 복구할 수 없으므로 먼저 백업해주세요. 화면 위치 등 일부 설정은 macOS의 `Cybermaid/DOAPet` 설정에 남습니다.

## AI 요청

사용자가 대화를 전송하거나 재시도·AI 일기 초안 생성을 요청하면 별도 설치된 Codex CLI가 사용자의 ChatGPT 인증으로 OpenAI에 요청합니다. 일반 답장에는 최근 대화 50개 이내, 프로필, 1차 일정, 최근 일기 14개 이내(본문 각 4,000자·총 24,000자 이내)가 참고 데이터로 전달됩니다. 일기 초안에는 선택 날짜의 대화와 기존 일기를 전달합니다. AI가 등록한 항목과 답장을 앱이 로컬에 저장합니다.

스티커는 AI 요청을 만들지 않고 AI 참고 기록에서도 제외합니다. 텍스트 속 커스텀 이모지는 이미지 대신 이름으로 전달합니다. 2차 일정의 제목·내용은 AI 문맥에 넣지 않습니다. 앱은 Codex 인증 토큰이나 브라우저 쿠키를 읽어 복사하지 않습니다. AI 이용에는 OpenAI의 개인정보 처리와 사용 조건이 별도로 적용됩니다.

## 웹 검색

설정에서 검색을 허용하면 최신 정보가 필요한 AI 질문에 Codex의 웹 검색을 사용할 수 있습니다. 검색어에는 필요한 공개 주제·지역·날짜만 사용하고 개인 기록은 넣지 않도록 AI에 지시합니다. 검색은 설정에서 끌 수 있고, 일기 초안에는 사용하지 않습니다. 이 규칙은 모델에 대한 지시이며 임의의 대화 입력으로 인한 모든 검색 동작을 완전히 보장하는 필터는 아닙니다.

## 키보드 반응

봉고캣은 macOS가 제공하는 전체 키 입력 횟수 변화만 확인합니다. 어떤 키나 문자열을 입력했는지 읽거나 저장하지 않습니다. 설정에서 반응을 끌 수 있습니다.

## 모바일과 알림

모바일 접속은 기본으로 꺼져 있습니다. 켜면 맥의 loopback 주소에서 서버를 열고, 사용자가 구성한 Tailscale HTTPS 연결로 접근합니다. 연결 코드 인증 후 기기의 세션 및 Web Push 구독 정보를 맥에 저장합니다. 등록한 이미지·대화·일정·일기는 인증된 연결 기기에서 접근할 수 있습니다. 연결 코드를 공유하지 마세요.

Web Push를 켜면 답장·리마인더 내용이 기기의 푸시 서비스를 통해 전달되며 잠금 화면에 표시될 수 있습니다. 모바일 설정에서 기기 연결을 해제하거나 맥 설정에서 연결 코드를 재발급할 수 있습니다. 맥의 앱이 종료되거나 잠자기 상태라면 새로운 답장·알림을 생성하지 않습니다.
